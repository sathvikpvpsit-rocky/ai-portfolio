# AI Portfolio & Engineering Sandbox

**Author & Maker:** Guna Sathvik Bezawada

## Overview
Welcome to my personal AI Portfolio! I built this highly-configured prototype as a dual-audience Android application using Kotlin and Jetpack Compose. It is designed to seamlessly showcase both the business impact of my work to recruiters and the deep technical architecture to senior developers.

## Core Integrations & Demos
* **FactForge AI Engine:** I integrated a hybrid knowledge graph and semantic vector validation sandbox. You can use it to verify AI outputs and detect hallucinations directly within the app.
* **Cloudflare EdgeShield & TokenVault:** I implemented format-preserving tokenization (FPE) and SHA-256 HMAC integrity signatures with Cloudflare Turnstile validation for robust edge security.
* **Interactive Terminal Mode:** For my fellow engineers, I built a CLI terminal (`>_`) right into the UI to explore my resume, telemetry, and architecture via simulated commands.
* **Dual-Audience Architecture:** I designed a dynamic state toggle to switch layouts instantly between high-level business metric cards and detailed engineering trade-off matrices.

## Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Native Android)
* **Architecture:** MVVM / Clean Architecture
* **Testing:** Robolectric
